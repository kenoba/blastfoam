## 1. Setting up the new machine

1. OpenFOAM-12 in `/opt/OpenFOAM/OpenFOAM-12`, this repository in
   `/opt/OpenFOAM/blastfoam` (the test runner and some scripts hard-code these
   paths; `BLASTFOAM_ROOT` overrides the repository root for the runner).
2. `source /opt/OpenFOAM/OpenFOAM-12/etc/bashrc; source /opt/OpenFOAM/blastfoam/etc/bashrc; ./Allwmake -j`
   and check the log for `error`/`undefined` (Allwmake can exit 0 after a failed sub-build).
3. Not tracked by git; copy by hand:
   - `external/eudetcode`: separate EuDetCode checkout and build (Tier 0 tests,
     planar ZND verifiers, the products fits in `utilities/thermo_fitter`).
   - `articles/`: literature PDFs (Balakrishnan 2009/2010, Cao 2013, ...).
   - The FOI 2013 raw measurements (`Measurements/TXT`; set `FOI2013_DATA`,
     see `tutorials/blastEulerFoam/FOI2013_TNT_1D_spherical/README.md`).
   - `report/goodman_surface_temperature_plan.md` (untracked, not part of this work).
   - Optional: Cantera in `/usr/local` (`tests/0D/verify_gas_kinetics.py`), a
     local gunIB1D build (`tests/1D/verify_gunib1d_benchmarks.py`).
4. Check: `python3 bin/run_blast_tests.py --tier 1` and
   `python3 tests/1D/verify_turbulent_mixing_diffusion.py` (10 s).

## 3. Open work, in order

1. **1D mixing calibration: done** (`mix/c*`, to 3 ms; numbers in
   `report/development_plan.md`, Stage 6). Burnt 17.6/25.9/47.8% for
   C = 0.005/0.01/0.03 (5.6% laminar); C = 0.005 follows the burn history of
   Balakrishnan et al. (2010) scaled to the charge. First-positive-phase
   impulse (`analysis/first_phase.py`) at 0.75/1.0/1.5 m: +12/+10/+6%,
   +23/+19/+12%, +55/+52/≥+52%, against their +60/+46% at Z = 0.80/1.38.
   C = 0.005 is the burn calibration; matching their impulse needs about three
   times their burn and raises the peaks by up to 28%. `monitor_mix.py`
   integrates all positive overpressure (later pulses included); use
   `first_phase.py` for comparisons. The baseline `s4_lam_new` has no probes
   at 0.781/1.347 m; rerun it with `setup_mix.py --C 0` if those are needed.
2. **Calibrated C at the gauge distances**: map the C run at 1.5 ms onto the
   7 m / 8 mm mesh (`map1d.py`, as `res/dx8`), continue with the fvModel, and
   compare at 2.83/4.47/6.33 m with the laminar `res/dx8`.
3. **2D shot 4 with the model** (`../FOI2013_TNT_2D_axi_ground`,
   `setup_foi2013_2d.py --pressureDelta 2000`). C has to be lower than in 1D
   because the 2D run resolves part of the mixing; consider scaling D with the
   cell size. A larger machine allows 2-4 mm in the mixing layer and the
   seeded-instability variants of G3b (`ChargeCompBAl_2D_axi_seeded`).
4. **The matched burn leaves most of the impulse gap** (final 1D numbers);
   the rest is multi-D flow, not the burn: resolve the fireball
   instabilities (2D/3D) instead of raising C.
5. **TNT/Al shots** (shot 5 and the others; `run_campaign.sh` runs the 1D/2D
   chain for all shots): the Al effect (+15-27% impulse) is the main target;
   rerun with the condensed-species products.
6. Parked runs for a larger machine: cylinder L/D 1 and 4
   (`ChargeCompBAl_2D_axi_cylinder`, stopped at 267/173 µs), the G3b 60 µs /
   1 mm-layer and seeded-charge variants.
7. Plan stages still open: Stage 4 (dispersed-phase method comparison, Gate 4)
   before the 3D `ChargeCompBAl` validation (Gate 5); Stage 1 Al2O3
   condensation (D4) and Al against experiments (D6).

## 4. Working rules used so far

- Long runs as Slurm batch jobs on `serie` (Section 5; on the old machine
  `setsid nohup`), each with a periodic monitor of health and case physics.
- `rm -rf` only with every path component guarded (`${VAR:?}`).
- After code changes update `UPDATES.md` and the Status columns of
  `report/development_plan.md`; new physics with a `tests/` case and
  `verify_*.py` registered in `bin/run_blast_tests.py`.
